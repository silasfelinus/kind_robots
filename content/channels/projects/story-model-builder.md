  body: >-
    Model Builder upgrades an existing record or makes new ones from it, one
    reviewable step at a time. Choose a Source record, then a Recipe, and the
    Run shows each output as a row; select a row to work through its Pitch,
    Fields & Prompts, Generate Assets and Commit stages, or use Auto-build all.
    Nothing is written to the source until Commit. The steps across the top
    move between Source, Recipe and Run, History reopens earlier runs, New run
    and Reset start over, and your latest run is restored when you come back.
    You need to be signed in.
